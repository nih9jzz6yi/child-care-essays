# 心跳乱、怕中风？七旬老人“护心记”一波三折，心脏“小耳朵”成功上锁！

> 更新时间：2026-09-16 (UTC+8)

71岁的郑大爷（化名），十年来总被一阵阵心慌困扰——心脏常毫无征兆地“扑通扑通”乱跳，医学上称为“心房颤动”。虽然长期服药控制，但问题仍然未能根除。

两个月前，郑大爷来到香港大学深圳医院心律失常科寻求进一步诊治。经详细检查，发现其心脏左上方一个名为“左心耳”的囊状结构内已形成了血栓，这正是房颤患者发生脑卒中的最大隐患。尽管经过抗凝治疗血栓暂时消退，但根源未除，风险依旧。

图源：科室科普合作伙伴

心律失常科李海鹰主任及其团队为郑大爷制定了周密的“治防结合”方案：计划通过微创手术，一举完成房颤射频消融和左心耳封堵，既纠正紊乱心律，又封堵住血栓形成的“老巢”，以最大限度预防未来卒中。
然而，治疗之路并非一帆风顺。首次手术中，房颤消融虽顺利完成，但到了关键的左心耳封堵环节，团队遇到了意想不到的挑战。郑大爷的左心耳解剖结构极为特殊，形态与常人差异显著，导致多种常规型号的封堵器均无法安全、完美地贴合释放，手术不得不暂停。
更大的难度在于郑大爷复杂的全身状况：他不仅患有10年高血压，还同时合并高脂血症、痛风、重度睡眠呼吸暂停综合征以及冠状动脉肌桥等多种疾病。这意味着，他的心脏承受着多重负担，血管条件复杂，任何治疗都必须慎之又慎。
面对这一难题，李海鹰主任及其团队并未放弃。依托丰富的临床经验，结合郑大爷独特的心脏结构，对现有各类封堵器型号的形态、规格与特性进行了全方位的深入研究和反复比对。
团队通过三维影像重建与计算机模拟，预先测试多种方案，最终从众多选择中，精准筛选出了最适合郑大爷心脏结构的唯一“钥匙”。
2025年12月5日，团队成功为郑大爷植入了量身选定的左心耳封堵器。
这场“一波三折”的手术，最终为郑大爷的心脏成功上了一把“安全锁”。它不仅降低了未来因房颤导致中风的风险，也让郑大爷有望摆脱对长期抗凝药物的依赖，规避了潜在的出血风险，实现了“身心”的双重解脱。

一、什么是左心耳封堵术？

>>>

>>>

>>>

人的心脏有四个房间，左心房上面长着个像小耳朵的“小口袋”，医学上叫“左心耳”。房颤病人的这个“小口袋”里特别容易形成血块，这些血块如果掉下来，随着血流跑到脑子里，就会堵住血管，导致“中风”（脑梗）；跑到其他地方，也会引起相应问题。

图源：科室科普合作伙伴

左心耳封堵术是个微创手术：

①　医生在大腿根部扎个小针眼；②　通过血管送进去一根细软的管子；③　管子顶端带个“小伞”（封堵器）；④　到心脏后，“小伞”打开，正好堵住“小口袋”的门口。这样血就进不去“小口袋”了，自然也不会在里面形成血块。

图源：科室科普合作伙伴

二、什么样的人需要考虑这个手术？

>>>

>>>

>>>

- 有房颤，且中风风险较高；
- 吃抗凝药容易出血：比如身上容易青紫、牙龈常出血、有过胃出血等；
- 不想长期吃抗凝药：觉得每天吃药麻烦，或者经常忘记吃药；
- 即使吃药还是中风过：说明光吃药效果不够；
- 像郑大爷这样有多种疾病的：高血压、糖尿病、肾功能不好等情况。

三、术后恢复怎么样？

>>>

>>>

>>>

防中风效果好：能把中风风险降低很多；减少出血风险：术后可少用或停用抗凝药；一次手术，长期保护：“小伞”放进心脏后就一直在那里工作，不用更换；生活更轻松：不用天天惦记吃药，也不用经常抽血检查。
房颤在老年朋友中是比较常见的情况，若长期得不到有效控制，会增加发生中风的风险。如果您或身边的家人出现以下情况，建议您可至医院相关门诊进一步咨询评估。

**1**

时常感到心慌、心跳不规律。

**2**

已被诊断为房颤，正在服用抗凝药物。

**3**

既担心发生中风，又对长期服用抗凝药物可能引起的出血风险有所顾虑。
