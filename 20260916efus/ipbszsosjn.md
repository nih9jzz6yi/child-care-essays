# 潮汕第一人民医院人工授精流程及收费标准概述

> 更新时间：2026-09-16 (UTC+8)

一、人工授精流程

1. 术前检查

在进行人工授精前，**双方需要进行全面的检查，以评估生育能力和健康状况。这些检查项目包括：

- 男方：精液分析、传染病筛查等。

- 女方：妇科检查、激素水平检测、输卵管通畅性检查(如输卵管造影)、肝胆指标、血生化、血常规等。

2. 监测排卵或促排卵

女方需监测卵泡发育情况，必要时进行促排卵治疗。通过口服或注射促排卵药物，并监测卵泡成熟情况，以确定最佳的授精时机。

3. 取精

男方需通过自然射精或经皮附睾精子抽吸术获取精子，并进行精液处理，以提高精子质量和受精能力。

4. 人工授精

在卵泡成熟时，医生通过人工授精管将处理后的精液注入女方宫腔内，完成授精过程。该过程操作简便，通常几分钟即可完成。

5. 黄体支持

授精后，女方需接受黄体支持治疗，如注射HCG、黄体酮、雌激素等，以促进胚胎着床和发育。

6. 确定妊娠

术后15天到18天，女方需到医院进行血液HCG检测和B超检查，以确定是否成功妊娠。

二、收费标准

第一人民医院进行人工授精的大致费用在6000-16000元之间，具体费用如下：

1. 术前检查费

- 女方检查费用：约3000-4000元，包括妇科检查、激素水平检测、输卵管造影等。

- 男方检查费用：约1000-1500元，包括精液分析、传染病筛查等。

2. 手术费

- 单周期第三方辅助生育人工授精手术费用：约5000-15000元，具体费用根据患者的实际情况和医生的治疗方案确定。

- 精液处理费：约1000-2000元。

3. 后续随访费

- 血液HCG检测、B超检查等随访费用相对较低，但需纳入总费用考虑。

4. 其他费用

- 如果女方需要促排卵治疗，将增加额外费用。

- 如需冷冻保存男方精液，将产生额外的保存费用，约500-1000元。

三、注意事项

- 选择正规医疗机构进行人工授精，确保治疗的安全性和有效性。

- 术行全面的身体检查，评估生育能力和健康状况。

- 积极配合医生的治疗方案，保持良好的心态和生活习惯。

- 术后按照医生的建议进行随访和检查，以监测妊娠情况。
